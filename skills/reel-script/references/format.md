# Script block format

Use this block for every script, in the channel's scripts file (one `## NNN ·` block per
script, blocks separated by `---`). Number scripts in sequence; never reuse a number.

```markdown
## NNN · <the hook, word for word>

- **Format:** <talking head / screen recording / B-roll / comedy>, what is on screen and
  when, on-screen text, ~<seconds>s. Shape: <1–5 from SKILL.md, or "method">.
- **Cover:** <3–6 word text for the cover frame>
- **Status:** draft | edited | approved (<who>, <date>) | shot | posted | parked (<why>).
  Shoot-day re-checks: <facts that can change>. Competitor check: <done, date | not run>.
- **CTA:** comment KEYWORD → <what the DM gives> | ends on a comment question
- **Source:** <where the idea came from, with the person's own words in quotes>

### Script

<Hook.>

<Body: one paragraph per beat. Spoken English. 110–150 words in total.>

<Takeaway as an action.>

<CTA line.>

### DM (KEYWORD)

<The full resource: numbered steps, links, requirements. Usable in ~10 minutes.>

### Caption

<2–4 sentences. First line = the hook or its key number. Ends with the CTA.
"(Not investment advice.)" on money topics. AI label if AI-made.>

### Source notes

- <Fact> (<source>, <date>).
- <Our maths: a × b = c.>
- <What not to say, and why.>
- Competitor check: <channels checked, date, result>.
- Conflicts between sources: <what, and the wording used>.
- No-ai-slop pass: <done; main fixes>.
```

## Status words

`draft` → `edited` → `approved` → `shot` → `posted`. `parked` means kept for later, with the
reason and the next step written down.

## Reply to the reviewer

1. The full script, DM and caption (they review in chat, not in the file).
2. 1–3 suggested edits, each with the new line written out and one reason.
3. Open facts or re-checks, in one line each.
4. One question at most: approve, or which edit to take.
